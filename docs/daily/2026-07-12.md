### 1. 로컬 → 클라우드 Supabase 전환
- `supabase link`로 클라우드 프로젝트(`bacwpzlenygqnowvcvnp`) 연결, 기존 5개 마이그레이션 `db push`.

  포맷으로 정리 (`EXPO_PUBLIC_SUPABASE_ANON_KEY` → `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` 등,
  apps/mobile·apps/web 양쪽 통일).

### 2. Toss Payments 빌링 연동 (테스트 키 기준)
- `apps/web/lib/payments/`에 `PaymentGateway` 인터페이스 분리 후 Toss 구현체 작성
  (PROJECT.md §4: 정산 방식 교체 가능하도록 설계).
- 카드 등록: 모바일 → `expo-web-browser`로 `apps/web`의 `/pay/billing-auth` 오픈 → 토스 SDK →
  `/api/billing/callback`(server, service_role)에서 빌링키 발급·저장 → `/pay/billing-done` →
  앱으로 복귀.
- 수락(낙찰) API: `apps/web/app/api/applications/[id]/accept` 하나가
  `accept_application()`(사용자 스코프) → 토스 빌링 결제 → `finalize_accepted_application()` /
  `revert_failed_acceptance()`(service_role) 체인을 전부 수행.
